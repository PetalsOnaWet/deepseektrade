加密货币 AI 交易直播

本系统实时展示一个币安 USDT 永续合约账户（当前权益 20 USDT）。所有决策由 DeepSeek 推理模型全权负责。AI 每 3 分钟获取最新行情、仓位与风险数据，输出结构化指令， 由执行引擎下单并记录日志，所有盈亏、日志与策略反思均同步在这里。

系统能做什么？

  • 直连币安合约账户，实时拉取余额、仓位与实际盈亏。
  • 展示 AI 的思维链、风控计划和每一笔执行记录。
  • 提供 ShareThis 分享按钮，方便输出直播战报。
  • 通过多周期信号筛选（3 分钟 / 4 小时 / 日线 / 周线）识别趋势机会。

是真实实盘吗？

是的。API Key 指向真实币安合约子账户，所有仓位、保证金、已实现盈亏均来自币安官方接口。 这不是模拟盘或历史回放，而是全天候实时交易。

使用什么模型？

决策核心是 DeepSeek 推理模型。系统对返回的 JSON 做严格校验：杠杆上限 10×、 单笔风险不超过净值的 3%，必须包含完整的保护计划，否则会拒绝执行。

核心策略

  • 趋势跟随：多周期共振才考虑开仓，弱趋势时宁可观望。
  • 两段式风控：行情获利 3%（未放大杠杆）后，将止损抬到保本位置。
  • 动态追踪：再扩张 1.5%~2% 后，启动 0.8%~1.5% 的波动率自适应追踪止损。
  • 风险敞口限制：最多持有 3 个品种，总风险敞口不超过净值的 3%。
